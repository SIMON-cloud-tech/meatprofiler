# 🥩 Meat Freshness Visualizer

Estimate meat freshness using chemistry-based decay logic. This tool helps users visually assess the freshness of meat products based on time, temperature, and decay models rooted in food chemistry.

## 🚀 Live Demo

Check out the live version: [Meat Freshness Visualizer](https://simon-cloud-tech.github.io/meatprofiler/)

---

## 📦 Features

- 🧪 Chemistry-based decay logic for freshness estimation  
- 📱 Mobile-friendly interface for quick field use  
- 📊 Visual indicators of freshness levels  
- 🔍 Simple UI for intuitive interaction
