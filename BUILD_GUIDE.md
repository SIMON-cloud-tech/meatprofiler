# How to Build and Install Meat Freshness Visualizer on Your Phone

## Method 1: Web App (Easiest - No Installation Required)

### Step 1: Use as Web App
1. Open https://meatprofiler.app in your phone browser
2. Tap menu (3 dots) and select "Add to Home screen"
3. App icon appears on your home screen
4. Works exactly like a native app with all features!

### Benefits:
- Instant access - no building required
- Works offline once loaded
- All features available including printing
- No installation permissions needed

---

## Method 2: Online Build Services (Recommended for Native App)

### Option A: AppGyver (Best for Beginners)
1. Go to https://www.appgyver.com/
2. Sign up for free account
3. Click "Create New App"
4. Choose "Web App" template
5. Import your web app URL: https://meatprofiler.app
6. Click "Build" and select "Android"
7. Download the APK file

**Pros:** Free, easy to use, no coding required
**Cons:** Limited customization, includes AppGyver branding

### Option B: Ionic Appflow (Professional)
1. Go to https://ionicframework.com/appflow
2. Sign up for free account
3. Connect your GitHub repository
4. Select "Build" > "Android"
5. Configure build settings
6. Download the APK

**Pros:** Professional results, more control
**Cons:** More complex, learning curve

### Option C: PhoneGap Build (Simple)
1. Go to https://build.phonegap.com/
2. Sign up for free account
3. Click "New App"
4. Upload your www folder (zip file)
5. Click "Build" for Android
6. Download the APK

**Pros:** Very simple, reliable
**Cons:** Basic features only

### Option D: PWA Builder (Microsoft)
1. Go to https://www.pwabuilder.com/
2. Enter your web app URL: https://meatprofiler.app
3. Click "Start"
4. Select "Android" platform
5. Download the PWA package
6. Install using PWA installer

**Pros:** Microsoft quality, PWA features
**Cons:** Requires PWA installer app

---

## Method 3: Direct APK from Web Files

### Step 1: Use Online APK Converter
1. Go to https://convertio.co/ or https://online-convert.com/
2. Upload your web files
3. Select "Convert to APK"
4. Download the result

### Step 2: Manual Build (Advanced)
1. Use https://replit.com/ (online IDE)
2. Create new Android project
3. Copy your web files to assets
4. Build and download APK

---

## Troubleshooting

### Build Issues
- **Platform errors:** Try a different platform from the list above
- **Upload failures:** Check file size limits, compress files
- **Build timeouts:** Try again during off-peak hours

### Installation Issues
- **"Install blocked":** Enable unknown sources in settings
- **"App not installed":** Uninstall previous version first
- **"Parse error":** APK corrupted, rebuild from platform

### Performance Issues
- **Web app version:** Works on all phones, instant access
- **Native APK:** Better performance but requires build time
